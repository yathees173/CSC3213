# 🖥️ 8086 Assembly Program

This repository contains basic **8086 Assembly Language programs** developed for learning and practical purposes.

The programs run in a DOS environment using **DOSBox**.

## 📚 Topics Covered

- Basic assembly instructions
- Registers
- Arithmetic operations
- User input and output
- Loops and conditions
- Procedures
- DOS interrupts

## 🛠️ Technologies Used

- 8086 Assembly Language
- DOSBox
- TASM or MASM
- Text editor or Visual Studio Code

## ▶️ How to Run

1. Open DOSBox.
2. Mount the project folder.
3. Assemble the program.
4. Link the object file.
5. Run the executable file.

Example:

```text
tasm program.asm;
link program.obj;
program.exe
